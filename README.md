# YouTube Home Page Clone

A pixel-perfect frontend replica of the YouTube homepage, built strictly using **HTML5** and **CSS3**. 

This project was created to master advanced CSS layout techniques, responsive design principles, and component-based UI structuring without the use of heavy frameworks.

## Features
* **Pixel-Perfect UI:** Closely mimics the actual YouTube sidebar, header, and video grid layout.
* **Responsive Video Grid:** Utilizes CSS Grid/Flexbox to dynamically adjust video cards based on screen size.
* **Pure CSS Hover Effects:** Smooth animations on sidebar links, buttons, and video thumbnails.
